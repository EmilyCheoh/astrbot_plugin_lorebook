# Lorebook - 世界书插件

基于正则匹配的轻量世界书实现。当用户消息命中条目正则时，自动将对应内容注入到 LLM 请求中，下一轮自动清理。

## 工作原理

每轮 LLM 请求前执行两个阶段：

1. **清理阶段**：从对话历史中移除上一轮注入的 XML 标签
2. **注入阶段**：扫描当前用户消息，正则匹配所有已启用条目，对命中条目做 RAG 去重（跳过已被 RAG 注入到 prompt 中的内容），将剩余条目按优先级排序后注入

## 配置方式

在 AstrBot 管理面板的「世界书 JSON 配置」文本框中粘贴 JSON。格式为 JSON 数组，每个元素是一本世界书。

### 字段说明

**世界书级别：**

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `book_name` | 世界书名称，用于日志 | `lorebook_0` |
| `enabled` | 启用开关，接受 `"T"`/`"F"` 或 `true`/`false` | `true` |
| `injection_position` | 注入位置：`user_message_before` / `user_message_after` / `system_prompt` | `user_message_after` |
| `tag_name` | XML 标签名称（仅字母、数字、连字符、下划线） | `Additional-Info` |
| `header_text` | 标签头部说明文本，留空则不添加 | `""` |
| `entries` | 条目集合，支持对象 `{"entry_1": {...}}` 或数组 `[{...}]` | — |

**条目级别：**

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `name` | 条目标识，留空则跳过 | — |
| `enabled` | 条目开关，接受 `"T"`/`"F"` 或 `true`/`false` | `true` |
| `priority` | 注入优先级，1 = 最高，10 = 最低，接受字符串或数字 | `5` |
| `regex` | 正则触发，接受 `"\|"` 分隔的字符串或字符串数组，任一匹配即触发 | — |
| `content` | 触发时注入的内容 | — |

### 正则示例

- `猫\|喵` — 包含"猫"或"喵"
- `(?i)hello` — 不区分大小写
- `\\b周末\\b` — 精确匹配（JSON 中反斜杠需转义为 `\\`）
- `[Cc]ity\\s?[Pp]op` — 正则元字符需转义
